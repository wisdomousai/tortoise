# Documentation site

The documentation site renders the repository's maintained Markdown with Astro Starlight. `scripts/docs-collect.ts` mirrors the source pages into `src/content/docs`, which is generated and ignored by Git. It preserves repository-relative page paths. Links to source files become GitHub links through `src/plugins/repo-links.ts`.

`bun run docs:build` generates the catalog reference, collects the pages and builds the site into `dist/docs`. The link validator checks internal links during that build. Tutorial imports use source files with `?raw`; `src/region.ts` extracts the named region and rejects a missing marker. Those checks establish that the excerpt exists. They do not establish that it represents an intermediate tutorial checkpoint.

The architecture views read `dist/reference/overview.json`. The generator reads explicit concept ownership from `scripts/overview-ownership.ts`, allowing README prose to change without changing the map's membership. `scripts/overview-curated.ts` supplies the explanatory references for the views. Generation checks their paths and named test references. It does not execute those tests.

Retired documentation routes are generated by `src/pages/docs/[retired].astro`. `scripts/docs-migrations.ts` maps each published fragment to its canonical destination. The redirect preserves the site's base path and query string. A reader without JavaScript receives a link to the destination guide. Repository links point directly to the canonical source page.

## Development

Run commands from the repository root:

```sh
bun run docs:dev
```

This generates the reference and starts the site with a watcher that mirrors changed pages. Use `bun run docs:build` for the static build and `bun run docs:preview` to serve that build. `bun run docs:collect` only updates the mirrored content.

`bun run docs:screenshots` captures the tutorial reference screenshots through the configured browser specs. Review the resulting image against the application before replacing a screenshot. The documentation build does not regenerate images.

Guide navigation is declared in `docs/site/sidebar.ts`. A workspace README remains available at its repository-derived route; tutorial routes are listed explicitly. Consult the [writing guidance](../styleguide.md) when changing prose and the [development checks](../development-and-testing.md) when changing supporting code.
