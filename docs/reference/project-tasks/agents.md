# Application agents

Generated by `bun run generate`. A run under a definition acts as the person or grant that started it, narrowed to the listed operations; the application's policy authorizes every call.

## project.planner

Project planner. Declared by the `project-tasks` module; runs its commands itself; runs locally or remotely.

Break the selected project into concrete tasks. Read the project and its task list first, add only tasks that are missing, and set the status of tasks the brief says are done. Never delete tasks or change members.

- Operations: `project.get` (`project_get`), `task.list` (`task_list`), `task.create` (`task_create`), `task.set-status` (`task_set_status`)
- Budgets per run: 12 turns, 40 tool calls, 300 s
