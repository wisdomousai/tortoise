# @tortoise/operator-ui

Input parts for operators at a point of work, as the `operator` shadcn registry: glove-sized targets, `hold-to-confirm`, state shown as icon plus text. Pull a part with `shadcn add`; you own the copy. Nothing here is a security boundary.

- Primitives: [UI registry](../../docs/primitives.md#ui-registry), [Approval request](../../docs/primitives.md#approval-request).
